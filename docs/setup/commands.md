Трек **Р**. Файл команды — `.kilo/commands/review-diff.md`: шаги (загрузить скилл `code-review`, собрать `git diff main...HEAD` и `git diff HEAD`, пройти чек-лист), формат результата (шаблон скилла `.kilo/skills/code-review/template.md`, ответ в чат), блок «Чего не делать» (★). Правила ревью в команде не переписаны — она ссылается на скилл.

### Вызов

Kilo, агент **code**, `training-2026-09-minimax-m3`, новая сессия, одна строка:

```
/review-diff
```

Что ревьюилось: незакоммиченный фикс SQL-инъекции в `ApplicationRepository::listApplications()` (`prepare()` + `bindValue` вместо конкатенации `?status=` / `LIMIT` и `query()`) — патч, который агент сделал в 2.2.3 ★, применён на время проверки и потом откачен. Тестов в диффе нет — по скиллу это blocker «баг-фикс без теста».

Лента (база Kilo): `skill code-review` первым вызовом → `git diff main...HEAD` + `git diff HEAD` + `git status` → `read template.md`, `read ApplicationRepository.php` → `glob`, `grep listApplications` → `ls tests/`.

## 2.4.2 · параметр `$ARGUMENTS` — что ревьюить

Параметр трека **Р**: путь к файлу или имя ветки. В теле команды (`.kilo/commands/review-diff.md:7-11`, блок «Параметр») четыре случая: **пусто** — один вопрос «Что ревьюить: путь к файлу или имя ветки?» и стоп; **файл** — дифф файла `main...HEAD` + незакоммиченное, если файл не менялся, то сказать это первой строкой и ревьюить файл целиком, всё «вне PR»; **ветка** — `git diff main...<ветка>`; **ни то ни другое** — сказать и спросить, похожее имя не подбирать.

Условия: Kilo, агент **code**, `training-2026-09-minimax-m3`, каждый вызов — новая сессия после `/reload`. Лента и токены — из базы Kilo.

| | Вызов 1 | Вызов 2 | ★ Вызов 3 |
|---|---|---|---|
| Команда | `/review-diff backend/src/Repository/ApplicationRepository.php` | `/review-diff d2/2.4.1-2.4.3-estinali` | `/review-diff` |
| Какое правило «Параметр» сработало | файл, в ветке не менялся | ветка | пусто |
| Шагов / вызовов инструментов | 4 / 8 | 23 / 36 | 1 / 0 |
| Токены: вход (+ из кэша) / выход + рассуждение | 65k (+60k) / 1,5k + 1,2k | 127k (+894k) / 3,5k + 11k | 0,9k (+28k) / 19 + 45 |
| Что ревьюил | весь файл, всё «вне PR», вердикта нет | дифф ветки: 2 markdown-файла | ничего |
| Итог | 7 замечаний «вне PR» | 1 major + 1 major + 4 minor + 1 «вне PR», **мержить после правок** | вопрос и стоп |

Параметр меняет результат: в вызове 1 предмет — PHP-код репозитория (SQL-инъекция, N+1), в вызове 2 — только markdown команды и этого документа, PHP не обсуждается; в вызове 3 ревью не начинается вовсе.
