### Сверка с кодом

- **Верно:** первый blocker — фикс без регрессионного теста, тестов на репозиторий действительно нет; minor про лишний `(string)`; N+1 вынесен строкой «вне PR» и на вердикт не повлиял.
- **Неверно (выдумано):** во втором blocker — «пустая строка `''` раньше давала `WHERE status = ''`». Старый код тоже пропускал фильтр при `''` (`if ($status !== null && $status !== '')`), поведение не менялось.
- **Неверно (выдумано):** major про эмуляцию — класса `DB` нет, есть `Database`, и в `backend/src/Database.php:24` явно стоит `PDO::ATTR_EMULATE_PREPARES => false`. Агент этот файл не открывал.
