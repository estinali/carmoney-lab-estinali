## Сверка с кодом (человек + Claude Code, по скриншотам)

Скриншоты открыты вручную, содержимое совпадает с описанием выше.

- **400001 → `review`** — совпадает с кодом. LTV 50 % ниже `ltv.approve_max = 60` (`backend/config/rules.php`), т.е. без пробега было бы `approve`; `review` даёт ветка `$mileage > $this->maxMileageForApproveKm` в `DecisionEngine::decide()` (порог `vehicle.max_mileage_for_approve_km = 400000`).
- **600000 → ошибка** — совпадает с кодом: `ApplicationValidator::validate()`, сообщение `sprintf('Пробег от 0 до %d км', max_mileage_km)` с `max_mileage_km = 500000`, HTTP 422.

Расхождения и замечания:

1. **Пользователь не видит, почему `review`.** На экране только «REVIEW» и «Одобренный лимит 0 ₽» — ни слова о том, что причина в пробеге выше 400 000 км. Правило есть в коде, но в интерфейсе оно не объяснено.
2. **Регистр.** В DOM и в API решение — `review`, на экране — «REVIEW»: CSS `.decision { text-transform: uppercase; }` (`frontend/styles.css`). Агент выше записал значение из DOM, а не то, что видит глаз.
3. **Техническое имя поля в ошибке.** Пользователь видит `mileage: Пробег от 0 до 500000 км` — с ключом `mileage`, а не с подписью поля «Пробег, км» (`frontend/app.js`, `showErrors()`: `field + ': ' + message`).
4. **Поле без ограничений.** `<input id="mileage" type="number">` без `min`/`max`, форма с `novalidate` — про лимит 500 000 км пользователь узнаёт только после отправки.

## ★ Второе место в интерфейсе, где видно правило про пробег

Кнопка **«Только рассчитать LTV»** — идёт в `POST /api/ltv` (`frontend/app.js:69`), а не в `/api/applications`, но проходит ту же `AssessmentService::assess()`, поэтому правило про пробег действует и тут. Проверено через тот же Playwright MCP (headless) из Claude Code, а не агентом Kilo:

1. Открыл `http://localhost:8080`, ввёл в «Пробег, км» `400001`, нажал «Только рассчитать LTV».
   Блок «Решение» (дословно): «Решение» `REVIEW`, «LTV» `50 %`, «Возраст авто» `7 лет`, «Одобренный лимит» `0 ₽`, «Номер заявки» `не сохранена`.
   Скриншот: `docs/setup/e2e_mileage_400001_calc_only.png`.
2. Открыл страницу заново, ввёл `600000`, нажал «Только рассчитать LTV».
   Блок (дословно): «Заявка не принята», пункт `mileage: Пробег от 0 до 500000 км`.
   Скриншот: `docs/setup/e2e_mileage_600000_calc_only.png`.

Замечание: в режиме «Только рассчитать LTV» заявка не отправляется, но ошибка всё равно озаглавлена «Заявка не принята» — заголовок блока `#errors` общий для обеих кнопок (`frontend/index.html`).

## Первая попытка (не удалась)

С конфигом из задания (`"command": ["npx", "@playwright/mcp@latest"]`) Playwright MCP запускал Chrome в видимом окне, и тот падал на старте (`SIGTRAP`): в GSettings-схемах GNOME этой машины нет ключей `font-antialiasing` / `antialiasing`, которые читает GTK-интерфейс Chrome. Агент честно записал, что шаг не удался, и снял только стартовую страницу через `google-chrome --headless`. Исправлено флагом `--headless` в `kilo.jsonc`: `"command": ["npx", "@playwright/mcp@latest", "--headless"]` — браузер работает без окна, GTK не нужен. Результаты первой попытки удалены, отчёт выше — второй прогон.
