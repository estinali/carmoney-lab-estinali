# code-rules

Правила для любой работы с кодом в этом репозитории.

1. Пороги и лимиты (пробег, LTV, суммы, сроки) не пишем числом в коде — берём из `backend/config/rules.php`.
2. Числа в `rules.php` и ожидания в тестах не меняем, пока человек прямо не сказал «меняем».
3. Каждый путь к файлу проекта в ответе — только в виде `файл:строка` (например, `backend/src/Domain/DecisionEngine.php:43`). Это касается любого ответа, в том числе отказа и встречного вопроса. Путь без строки — нарушение. Номер строки бери только из файла, который открыл в этой сессии; угадывать номер запрещено — сначала открой файл.
4. Если просьба противоречит правилу (например, «впиши 400000 прямо в код») — не делай молча: скажи, какой пункт нарушается, предложи как по правилу и жди ответа.
